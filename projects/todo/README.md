# 나의 할 일 목록 (Todo App)

HTML, CSS, JavaScript만으로 만든 간단한 할 일 관리 웹 앱입니다. 별도의 설치나 서버 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- **할 일 추가**: 입력창에 내용을 적고 `추가` 버튼을 누르거나 Enter 키를 누르면 추가됩니다.
  - 빈 내용이나 이미 등록된 할 일은 추가되지 않습니다.
- **완료 표시**: 체크박스를 눌러 완료/미완료를 전환합니다.
- **삭제**: 각 항목의 `✕` 버튼으로 삭제합니다.
- **필터**: `전체` / `진행중` / `완료` 버튼으로 원하는 항목만 볼 수 있습니다.
- **완료된 항목 일괄 삭제**: 완료한 할 일을 한 번에 지웁니다.
- **통계**: 전체 할 일 개수와 완료 개수를 보여줍니다.
- **자동 저장**: 브라우저의 LocalStorage에 저장되어 새로고침하거나 다시 열어도 목록이 유지됩니다.

## 실행 방법

1. 이 저장소를 내려받습니다.
   ```bash
   git clone <저장소 주소>
   ```
2. `index.html` 파일을 더블클릭해 브라우저에서 엽니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (입력창, 필터 버튼, 목록) |
| `style.css` | 화면 디자인 |
| `main.js` | 추가·완료·삭제·필터·저장 기능 |

## 사용 기술

- HTML5
- CSS3
- JavaScript (프레임워크 없이 순수 JavaScript)
- LocalStorage
